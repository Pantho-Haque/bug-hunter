# CodeQuest 3D

Starter shell for the local-first 3D JavaScript learning game described in the project documents.

## Run locally

```bash
npm install
npm run dev
```

## Current scope

The starter provides a responsive map screen and Mission 01 layout with a placeholder third-person meadow, editable starter code, run/reset interaction, quiet mode, and reduced-motion styling. It deliberately does **not** execute player code, render a real Three.js scene, save data, or implement progression yet.

Read [the implementation plan](docs/IMPLEMENTATION_PLAN.md) before extending it.
