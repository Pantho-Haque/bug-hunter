# Decide the reading baseline and Meadow sequence

## Status

- State: Evidence gathering
- Owner: Curriculum owner, name pending
- Required reviewers: Product, research, UX and accessibility
- Blocks: Final first-zone copy, starter code, hints, and mission production

## Decision question

Does the Grade 3 to Grade 5 English baseline and M01 through M06 sequence work for children ages 8 through 12 without adult solution coaching?

## Proposed learning sequence

| Mission | Primary idea | Child-facing transfer |
|---|---|---|
| M01 | Sequence | Code order controls action order |
| M02 | Facing and turns | Direction changes what forward means |
| M03 | Collect | An action works when position and facing are valid |
| M04 | Interact | Code changes a meaningful object state |
| M05 | Plan and debug a route | A prediction can be tested and revised |
| M06 | Meadow checkpoint | Combine prior commands in a new route |

Do not introduce functions before Echo Forest, except the game API's function-call syntax as an action phrase. Explain that syntax without teaching function declarations in Meadow.

## Copy constraints

- Put a short observable goal before terminology.
- Use exact API and JavaScript syntax.
- Keep the active instruction to one action.
- Pair concise text with world cues and optional read-aloud.
- Use a four-stage hint ladder and an analogous example.
- Avoid idioms, sarcasm, ability labels, and shame.

## Evidence required

- Curriculum review of goals, examples, misconceptions, transfer variants, and reading load.
- Five to eight formative child sessions spanning ages 8 through 12.
- Score M01 completion, independent next action, transfer, recovery, hint stage, and assistance.
- Include keyboard, zoom, reduced-motion, and read-aloud observations.

## Decision rule

Accept only if the sessions reveal no repeated critical confusion about the goal, editor, Run, facing, source order, or feedback. Age-correlated failure requires narrower copy or differentiated help, not a silent broad-audience assumption.
